# Dataset

This project uses a used-car dataset containing vehicle specifications and historical selling prices.

The raw CSV dataset is not included in this repository.

## Dataset Source

The dataset should be downloaded from the original Kaggle/source page used for this project.

After downloading the dataset, place the CSV file in the project directory as required by the notebook.

## Expected Dataset Columns

The dataset should contain columns such as:

* `name`
* `year`
* `selling_price`
* `km_driven`
* `fuel`
* `seller_type`
* `transmission`
* `owner`
* `mileage`
* `engine`
* `max_power`
* `torque`
* `seats`

## Note

Please review and follow the dataset's original license and redistribution requirements before sharing the raw CSV publicly.
